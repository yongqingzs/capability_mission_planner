# 任务级规划与 Nav2 集成

`capability_mission_planner` 输出的是任务级路线，不是要求 Nav2 逐栅格跟踪的控制
轨迹。它负责能力匹配、任务分配、访问顺序、跨地图动作、共享资源预约和粗粒度
时间估计；Nav2 负责实时 costmap、footprint、局部避障、控制和恢复行为。

本项目借鉴 Navigation2 的三项思想：

1. 用障碍物距离生成软代价，使任务级距离排序更接近实际导航代价；
2. 用机器人净空半径和安全余量做粗粒度可达性筛选；
3. 用任务位置容差处理“到目标附近作业”，而不是要求中心精确落在一个栅格。

离线栅格路径用于分配解释、时间估算和 PNG 可视化。真正执行时，应把
`plan.json` 中每个停靠点转换为 Nav2 导航目标，由 Nav2 基于最新 costmap 重新规划。
楼梯、电梯、门和窄通道等共享资源仍由任务规划器提供强约束和时间窗；普通区域
的 CBS 时间表是参考调度，不能替代动态障碍处理。

推荐闭环：

```text
离线任务规划 -> plan.json -> Nav2 逐段导航
      ^                         |
      +-- 不可达/超时/失败反馈 --+
```

规划器不复制 `nav2_costmap_2d`、Smac Planner 或 ROS2 控制器，保持任务级模块边界。
