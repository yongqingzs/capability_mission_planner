# 任务级规划与 Nav2 集成

`capability_mission_planner` 输出的是任务级路线，不是要求 Nav2 逐栅格跟踪的控制
轨迹。它负责能力匹配、任务分配、访问顺序、跨地图动作、共享资源预约和粗粒度
时间估计；Nav2 负责实时 costmap、footprint、局部避障、控制和恢复行为。

本项目借鉴 Navigation2 的三项思想：

1. 用障碍物距离生成软代价，使任务级距离排序更接近实际导航代价；
2. 用机器人净空半径和安全余量做粗粒度可达性筛选；
3. 用任务位置容差处理“到目标附近作业”，而不是要求中心精确落在一个栅格。

离线栅格路径用于分配解释、时间估算和 PNG 可视化。真正执行时，应把
`plan.json` 中每个停靠点转换为 Nav2 导航目标，由 Nav2 基于最新 costmap 重新规划。
楼梯、电梯、门和窄通道等共享资源仍由任务规划器提供强约束和时间窗；普通区域
的 CBS 时间表是参考调度，不能替代动态障碍处理。

推荐闭环：

```text
离线任务规划 -> plan.json -> Nav2 逐段导航
      ^                         |
      +-- 不可达/超时/失败反馈 --+
```

规划器不复制 `nav2_costmap_2d`、Smac Planner 或 ROS2 控制器，保持任务级模块边界。

## 大地图加速

启用 `planner.traversal.downsample_costmap` 且将
`coarse_search_factor` 设为大于 1 时，任务规划直接在 N x N 原始栅格保守合并
后的粗地图上进行（区域内任一障碍会使粗栅格不可通行，净空取最小值，代价取最大值）。
这与 Navigation2 的 `downsample_costmap` 思路一致。导出的路线是任务级近似路径，
实际执行必须交给 Nav2 基于实时 costmap 和 footprint 重新规划。

CLI 会分别输出地图加载、任务规划、结果导出和总耗时，便于判断降采样是否有效。
与“粗估价后原分辨率精化”相比，该模式能显著减少大地图搜索时间，但会降低任务级
路径几何精度。窄通道地图建议从 `factor: 2` 开始测试，若粗地图封死通道则回退到
`factor: 1`。

在 bdz1（约 2365x1152）基准上，开启 `factor: 2` 后，02 场景规划耗时约从
8.8 秒降至 1.9 秒，03 场景约从 5.2 秒降至 1.1 秒。该结果依赖地图结构、任务
数量和缓存命中率，不应直接外推到所有地图。
